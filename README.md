## 存证原则
1. 每份报告/协议发布时记录 SHA-256
2. 时间戳锚定（OpenTimestamps .ots）——流程就绪；首份 .ots 打戳待家电脑执行（见存证说明.md）
3. 区块链存证（比特币升级锚定）——随 .ots 升级执行，当前为待打戳状态
4. 证据公开、不可抵赖、可复核
